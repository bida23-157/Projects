## 🧠 Mapping Mental Health Dashboard
Explores mental health survey data across regions and demographics.  
Includes heat maps, slicers, and insights into mental health support access.

📌 Fraud Detection Model
This project builds a fraud detection model using Python and machine learning to classify credit card transactions as either fraudulent (1) or legitimate (0). The dataset contains 1 million transactions with behavioral and categorical features such as transaction distance, chip usage, and online order status.
The model pipeline includes:
Data preprocessing (scaling continuous features, handling categorical variables)
SMOTE oversampling to address class imbalance
Logistic Regression classifier for probability-based fraud detection
Evaluation with precision, recall, F1-score, ROC-AUC, and PR-AUC
Key Results:
Recall (fraud cases): ~95% — most fraud is detected
Precision (fraud cases): ~57% — some false alarms, but manageable
ROC-AUC: ~0.98, PR-AUC: ~0.75 — strong overall performance
